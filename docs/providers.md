# Provider 指南

ShotForward 将 Agent、图片和视频能力放在明确的 Provider 边界之后。项目保存意图、输入快照和生成结果，不把核心数据模型绑定到某一家服务商。

## 当前适配器

| 能力 | 适配器 | 凭据方式 |
| --- | --- | --- |
| Studio Agent | 本机 Codex、ShotForward Runtime | 本机登录或运行环境配置 |
| 图片生成 | Codex 订阅能力 | 本机 Codex 登录 |
| 视频生成 | Seedance、MiniMax H3、Wan | Provider API Key 与端点配置 |

实际可用能力取决于版本、账户权限、地区和服务商状态。界面只应展示 daemon 已确认可用的模型和功能。

### 视频服务区域

- MiniMax 中国区与国际区是两个独立 Provider。中国区固定使用 `https://api.minimax.cn`，国际区固定使用 `https://api.minimax.io`，凭据不可跨区复用。两个区域均可配置 `MiniMax-H3` 和 `MiniMax-H3-Max`。
- `MiniMax-H3` 支持 768P/2K、4–15 秒；`MiniMax-H3-Max` 支持 480P/768P、5–15 秒，不支持 2K。
- Wan 3.0 使用阿里云 Model Studio 工作空间专属地址。模型、Endpoint URL 和 API Key 必须属于同一区域；配置界面从完整工作空间 URL 识别北京、新加坡、东京、法兰克福或弗吉尼亚等区域，不会跨区回退。

## 凭据与配置

- API Key 和访问令牌写入操作系统安全存储，不进入项目数据库、日志、URL 或前端持久化状态。
- 数据库仅保存非敏感设置和凭据引用。
- 新配置应先验证，再设为可选默认项；删除配置前要处理仍在引用它的任务或项目。
- 错误响应应保留稳定的错误类别、是否可重试和请求编号，同时避免暴露上游密钥或完整响应体。

Provider 配置通过 daemon API 管理。Web UI 不应直接调用第三方生成服务。

## 能力模型

适配器需要显式声明它支持的操作及约束，例如：

- 文本生成图片、参考图生成图片；
- 文本生成视频、首帧或首尾帧生成视频；
- 支持的宽高比、时长、分辨率和输入数量；
- 同步、轮询或流式任务语义；
- 可重试错误、取消与超时行为。

不要因为服务提供“OpenAI 兼容”接口就推断它支持图片、视频、流式或某个具体字段。能力必须由适配器实现并通过契约测试确认。

## 添加 Provider

新增适配器时至少需要：

1. 在 daemon 中实现规范化请求、响应和错误映射。
2. 声明能力和输入限制，并为其添加契约测试。
3. 使用统一的凭据存储，不把秘密传给前端。
4. 保存生成输入快照、上游任务 ID 和结果来源。
5. 定义超时、取消、轮询、重试和进程恢复行为。
6. 在中英文界面中提供清楚的配置和错误提示。

生成服务的价格、条款与内容政策可能变化；ShotForward 不应在代码或文档中承诺未经 Provider 保证的额度、延迟或输出权利。
